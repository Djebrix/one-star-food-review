## What it does

`main.py` writes exactly one sentence — an alien tourist's one-star review
of planet Earth that still slips in a genuine compliment about the food —
to `/output/entry.txt` (1–200 characters, UTF-8, deterministic).

## Run

```sh
python3 main.py
```
